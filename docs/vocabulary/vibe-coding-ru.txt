# Vibe-coding vocabulary for Russian dictation: names and acronyms written
# in Latin letters, and how a Russian speech model tends to hear them.
# Paste it into the Vocabulary sheet's Text view (Labs › Vocabulary text view) or
# load it with the loop in docs/features/vocabulary.md.
# One term per line: Term | sounds like, …
#
# Only names, acronyms, files, and commands belong here. Russian IT jargon
# that takes case endings (коммит, пуш, ревью, промпт, скилл, репозиторий,
# деплой, хоткей, тултип, лендинг, артефакт, канбан) stays in Cyrillic, so
# it isn't listed: a term here would turn «в репозитории» into Latin.
#
# Parakeet's biasing takes the first 64 terms and skips paths and file
# names (anything with . / @ : \ _), so those sit at the end, where AI
# cleanup still uses them.
