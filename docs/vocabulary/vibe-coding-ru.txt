# owner dictates, written as he writes them, and how a Russian speech model
# tends to hear them.
#
# This is the list Labs › Russian vibe coding adds, and the one "Set me up
# like Denis" offers: the Vocabulary of presets/deniskey.json. It is written
# from that file by scripts/export-preset, so change the preset, not this
# file (dictation::presets holds the two to each other).
#
# To use it without the Labs feature, paste it into the Vocabulary sheet's
# Text view (Labs › Vocabulary text view) or load it with the loop in
# docs/features/vocabulary.md. One term per line: Term | sounds like, …
#
# Parakeet's biasing takes the first 64 terms and skips paths and file
# names (anything with . / @ : \ _), so those sit past the 64th line, where
# AI cleanup still uses them.
