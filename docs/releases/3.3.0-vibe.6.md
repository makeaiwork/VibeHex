# VibeHex 3.3.0-vibe.6

- New in Labs: Files (macOS). Transcribe audio and video files, clean up their text, and ask
  for your own versions, each a tab, with follow-up questions; save as .md or .txt.
- New in Labs: Stop shortcut (macOS). Start dictating with your shortcut and finish with
  another key, Return by default, so the text lands where you were typing.
- New in Labs: Listen to the recording (macOS). A player in Files and Meetings; the word
  playing lights up, and a faster speed keeps the voice's own pitch.
- New in Labs: Collapsible sidebar. Fold the sidebar into a column of icons.
- New: AI cleanup on Codex, with your ChatGPT plan (Output › AI cleanup › Runs on › Codex,
  with Clean up on your own server on). A dictation waits up to a minute for it.
- New: A finished meeting has Summary and Transcript tabs, and Requests (with Clean up on
  your own server on) to ask about it or clean its transcript up turn by turn.
- New: Meetings › Settings › Notes › Written by can pick Codex or AI cleanup's model for full
  notes, also when Apple Intelligence isn't available.
- New: An About pane, and "VibeHex" at the top of the sidebar. Send feedback writes to the
  developer by email, with your version in the subject.
- Changed: Labs can show only the features VibeHex added. Russian vibe coding turns on every
  one of them except Stop shortcut.
- Changed: Long text reads softer in dark mode.
