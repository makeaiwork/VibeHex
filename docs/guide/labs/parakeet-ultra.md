# Parakeet Ultra

**What it does.** Adds one more speech model to the picker: Parakeet Ultra, a
post-trained version of Parakeet v3 made by Moondream. It runs on your
computer, offline, and covers the same 25 languages as Parakeet v3,
Russian included.

**Turn it on when.** You use Parakeet v3 and want to try a variant of it.

**Leave it off when.** You are happy with your model. VibeHex never
recommends Ultra over the others.

**Needs.** A download of about 740 MB once you pick it. It detects the
language from the audio, so the language setting does not steer it, and it
does not write while you talk.

**Good to know.** It is experimental: VibeHex has run it only on Linux so far.
While Ultra is your dictation model the switch cannot be turned off; choose
another model first. With Labs › Vocabulary biasing on, your Vocabulary
biases it like other Parakeet models. Licence: CC BY 4.0.

**Where.** Labs › Parakeet Ultra (`labs.parakeet_ultra`). Then pick it in
General › Speech model.

**Asked as.** "Where is Parakeet Ultra?"; "Why can't I turn off Parakeet
Ultra?"; «Куда делась модель Parakeet Ultra»; «Как включить Parakeet Ultra».
