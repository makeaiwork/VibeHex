# Playground

**What it does.** Adds a Playground item to the sidebar that swaps the window for a list of "stories": sample screens, the recording HUD, and capsules shown with made-up data. Nothing real runs in them.

**Turn it on when.** You build or test VibeHex itself, or are curious how its screens and animations look. It is a developer tool; ordinary users don't need it.

**Leave it off when.** You only want to dictate. It changes nothing about dictation.

**Needs.** Nothing else.

**Good to know.** Only dev builds of VibeHex list this lab. It applies at once. Besides the sidebar item, Shift+Command+D opens it on a Mac (View › Playground), Ctrl+Shift+D elsewhere. Off, none of these work.

**Where.** Labs › Playground (`labs.playground`).
