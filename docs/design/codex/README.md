| [Meetings.dc.html](Meetings.dc.html) | Список записей слева (идущая запись, поиск, дни); справа вкладки Summary, Transcript, Requests; открыто меню сессий вопросов к встрече, под ним сессия чатом | Модели Codex в Meetings |
| [MeetingsSettings.dc.html](MeetingsSettings.dc.html) | Meetings › Settings: кто пишет заметки, модель, промпт заметок (Edit…), вопросы к встрече и их модель | Модели Codex в Meetings |
| [Composer.dc.html](Composer.dc.html) | Поле запроса (вариант B: модель, ризонинг и Send в компактном ряду под полем): покой, наведение, фокус, ввод, три строки, шесть с прокруткой, ответ идёт (Send становится Stop), остановлено, меню модели и ризонинга по клику на пилюлю | Модели Codex в Files и Meetings |

| [Cleanup.dc.html](Cleanup.dc.html) | Files, вкладка Cleanup: текст после чистки, быстрые запросы и поле «Ask about this text»; вопрос открывает новую сессию в Requests | Модели Codex в Files |
| [QuickPrompts.dc.html](QuickPrompts.dc.html) | Files › Settings › Quick requests: список запросов (Structure, Summary, Action items, + Add request), имя, промпт по умолчанию для языка модели речи, Reset to default, Save | Промпты быстрых запросов |
| [Playback.dc.html](Playback.dc.html) | Прослушать запись, сравнение вариантов. A (сверху): в ряду вкладок одна кнопка 24 pt «⏸ 01:34»; Files › Original в тёмной теме, идёт звук; Meetings › Transcript в светлой, пауза на выбранном слове, подсказка «Play from» под словом. Внизу: B — плеер в нижнем ряду поля запроса; C — плеер над полем (назад на 5 с, ползунок, 1×); A+ — линия под вкладками как ползунок, состояния слова, клавиши. Нижний ряд: D — Play первой кнопкой в ряду быстрых запросов, плеер разворачивается на их месте (свёрнуто, играет в Files и во встрече, свёрнуто на паузе с местом на кнопке) | Сверить транскрипт с записью |
| [Transcript.dc.html](Transcript.dc.html) | Читаемый транскрипт встречи, четыре варианта на одной и той же короткой планёрке. A: подряд идущие реплики одного говорящего одним блоком, имя и время один раз, время реплики при наведении. B (рекомендую): имя только при смене говорящего, время каждой реплики в тихой колонке слева, при наведении ▶. C: тонкая цветная полоска говорящего, время только при наведении. D: реплики ближе 30 с сливаются в абзацы, время чипом в начале абзаца | Читаемый транскрипт |

На холсте рядом семь заметок: сама идея, сворачивание боковой панели, цвета из темы OpenCode, какую модель выбирать для чего, где
ещё выбирается модель, как устроены запросы чатом, приватность (разовые треды, без инструментов, в Labs выключено по умолчанию).

Как открывать: двойной щелчок по любому `.dc.html`. Рядом лежит `support.js`, это локальная замена
движка холста. Логотип VibeHex берётся из `packaging/linux/icons/`. Шрифты Inter и JetBrains Mono грузятся из
интернета, без сети будут системные.
Макеты статичные: списки и меню нарисованы раскрытыми. Окно в тёмной теме (Playback: тёмная и светлая), ширина 980, как снимки
`--snap`.
